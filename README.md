# library-website
📚 This is a beginner-level HTML & CSS project for building a simple Library Website. The goal is to help Xheni practice structuring web pages, styling with CSS, and organizing code properly.

The project includes:

- A navigation bar
- A homepage with book listings
- An author section
- A search bar (UI only)
- A contact form

🔧 Built With:
HTML and CSS3

🎯 Learning Goals:
Practice HTML daily
Use CSS for layout and styling
Work with navigation menus and html elements like div, h1, p, span, etc.
Push and manage code using Git and GitHub

📅 Daily Progress Plan:
The project is broken down into daily tasks. Each day’s progress is committed and pushed to GitHub, showing steady improvement and clean version control.
